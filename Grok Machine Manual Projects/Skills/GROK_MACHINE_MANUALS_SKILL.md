## Integrity

1. Extract only from RA, drawings, photos, questionnaire.  
2. Never invent energy isolation methods, E-stop counts, voltages, or safety devices.  
3. Photo evidence upgrades RA wording when as-built differs — note the source.  
4. Residual risk: point to Machine Safety Assessment; do not dump full residual-risk appendix.  

## Section drafting notes

- **Sec 3:** Narrative, max ~2 pages; no hazard register table in body; end with RA reference.  
- **Sec 4:** Table of isolation points; Tag-Out / Tag-In as flowcharts.  
- **Sec 5:** E-stop locations from RA/photos; activation/reset flowcharts.  
- **Sec 6:** Process from RA; cycle start = two-hand control when RA states it.  
- **Sec 8–10:** Parameters from RA; drawings/alarm lists → PLACEHOLDER if missing.  
- **Sec 12:** Liability disclaimer once; sign-off once; role only.
